Régua 1

Queda livre sem resistência do ar

A única força é o peso, então a aceleração é constante. Integrando duas vezes, chegamos à posição.

  1. Ponto de partida
    a(t) = −g = − m/s²
  2. Integrar a aceleração
    v(t) = ∫ a(t) dt = −g·t + C1

    Parte do repouso: v(0) = 0 ⇒ C1 = 0 ⇒ v(t) = −g·t

  3. Integrar a velocidade
    y(t) = ∫ v(t) dt = −½·g·t² + C2

    Sai do avião: y(0) = m ⇒ y(t) = − ½·g·t²

  4. Conferindo com a derivada
    y′(t) = −g·t = v(t)  ·  v′(t) = −g = a(t) ✓

O sinal negativo indica movimento para baixo. Nos mostradores usamos o módulo |v|.

Régua 2

Altímetro barométrico

O altímetro não mede altura: mede a pressão do ar e converte em altitude usando uma função exponencial.

  1. Pressão diminui com a altura
    dP/dh = −ρ·g
  2. Ar como gás ideal
    ρ = P·M / (R·T)  ⇒  dP/dh = −P / H

    H = R·T / (M·g) ≈ m (escala de altura)

  3. Separar variáveis e integrar
    ∫ dP/P = −∫ dh/H  ⇒  ln P = −h/H + C
  4. Função exponencial
    P(h) = P0·e−h/H

    P0 = 1013,25 hPa (nível do mar)

  5. O que o altímetro calcula (função inversa)
    h = −H·ln(P / P0)

Régua 3

Resistência do ar e velocidade terminal

O ar empurra para cima com força que cresce com v². Pela 2ª lei de Newton:

  1. Forças
    m·dv/dt = m·g − k·v² ,   k = ½·ρ·Cd·A
  2. Velocidade terminal (dv/dt = 0)
    vt = √( 2·m·g / (ρ·Cd·A) )
  3. Resolvendo a equação diferencial
    v(t) = vt·tanh( g·t / vt )
    s(t) = (vt²/g)·ln cosh( g·t / vt )
  4. Limite
    limt→∞ v(t) = vt·limt→∞ tanh(…) = vt·1 = vt
  5. 99% de vt
    tanh(g·t/vt) = 0,99 ⇒ t = (vt/g)·atanh(0,99)
